📘 How to Load YOUR Images from Google Drive (No More Fallbacks!)

🔹 Step 1: Upload & Share Your Image
1. Go to drive.google.com
2. Upload your image (e.g., forest-photo.jpg)
3. Right-click the file → Share
4. Change "General access" to "Anyone with the link can view"
5. Click "Copy link"
🔹 Step 2: Extract the File ID
The link looks like:
https://drive.google.com/file/d/YOUR_FILE_ID_HERE/view
Copy only the YOUR_FILE_ID_HERE part.
🔹 Step 3: Update the Code
Open your forest-canopy.html file. Find the forestImageAssets array and replace the placeholder IDs:

// REPLACE THIS: { id: "YOUR_ACTUAL_DRIVE_FILE_ID", title: "My Forest Photo", ... }
🔹 Step 4: Test It!
After updating, refresh the page. Your image will load directly from Google Drive (green "Drive" badge appears).
✅ Pro Tip: The URL format for Drive images is:
https://drive.google.com/uc?export=view&id=YOUR_FILE_ID
